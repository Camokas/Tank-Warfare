# Tank Warfare

Учебная сетевая игра для Unity 6 и WebGL. Два игрока выбирают класс танка, подключаются по шестизначному адресу комнаты и играют до трёх очков.

## Что уже работает

- фиксированная камера сверху-спереди, охватывающая арену целиком;
- серверная генерация симметричного уровня из разрушаемых и неразрушаемых кубов;
- управление стрелками и выстрел на пробел;
- тяжёлый, средний и лёгкий танки с разными здоровьем, скоростью, уроном, перезарядкой и скоростью пули;
- авторитетный сервер: движение, столкновения, пули, урон, стены, счёт и итоговая статистика считаются только на сервере;
- плавная интерполяция серверных снимков на клиентах;
- матч до 3 очков, экраны победы/поражения и статистика матча;
- локальная совокупная статистика: ник, победы, любимый танк, метры, выстрелы и стены;
- зашифрованная AES-запись с HMAC-проверкой целостности и резервной копией. В WebGL Unity сохраняет PlayerPrefs в IndexedDB браузера;
- WebSocket для редактора/desktop и нативный браузерный WebSocket-мост для WebGL;
- автоматически создаваемые префабы-заглушки и подготовленные параметры Animator.

## Быстрый запуск в редакторе

1. В папке `Server` выполните `npm install`, затем `npm start` (Node.js 20+).
2. Откройте `Assets/Scenes/SampleScene.unity` и нажмите Play.
3. В одном экземпляре нажмите «Создать игру» и скопируйте адрес комнаты.
4. Запустите второй экземпляр игры или второй WebGL-билд, введите адрес и нажмите «Подключиться».

Клиент в редакторе по умолчанию использует `ws://localhost:8080`. Поле сервера есть в главном меню, поэтому адрес можно менять без пересборки.

## Публикация на itch.io

Браузер не может принимать прямые подключения от другого игрока. Поэтому показанный в игре «адрес» — безопасный короткий код комнаты, а оба клиента соединяются с WSS-сервером.

1. Разверните содержимое `Server` на любом Node/Docker-хостинге с HTTPS. Контейнер слушает переменную `PORT`.
2. Задайте `ALLOWED_ORIGINS` фактическим origin WebGL-iframe (обычно `https://html-classic.itch.zone`; точное значение видно в заголовке `Origin` запроса). Несколько адресов перечисляются через запятую. Пустое значение удобно только для локальной разработки.
3. В меню клиента укажите выданный серверу адрес `wss://...`.
4. В Unity выберите `Tools → Tank Warfare → Build WebGL`.
5. Упакуйте **содержимое** `Builds/WebGL` в ZIP и загрузите на itch.io как HTML-проект.

Обычный `ws://` на HTTPS-странице блокируется браузером; для itch.io обязательно нужен `wss://`.

## Замена моделей и анимаций

Заглушки лежат в `Assets/TankWarfare/Resources/Prefabs`. Если их ещё нет, Unity создаст их после компиляции; вручную это можно повторить через `Tools → Tank Warfare → Rebuild Placeholder Prefabs`.

Можно заменить дочерние меши, сохранив компонент `TankView` на корне и объект башни с именем `Turret`. Animator уже находится на корне. Ожидаемые параметры контроллера:

| Параметр | Тип | Назначение |
|---|---|---|
| `MoveSpeed` | Float | модуль скорости движения |
| `Fire` | Trigger | выстрел |
| `Hit` | Trigger | получение урона |
| `Death` | Trigger | уничтожение |
| `Respawn` | Trigger | новый раунд |

Без Animator Controller игра работает без ошибок — вызовы активируются автоматически после его назначения.

## Где находится логика

- `Assets/TankWarfare/Scripts/Gameplay/GameClient.cs` — состояния игры, ввод, UI и применение снимков;
- `Assets/TankWarfare/Scripts/Gameplay/WorldView.cs` — кубическая карта и снаряды;
- `Assets/TankWarfare/Scripts/Gameplay/TankView.cs` — сменяемое представление танка и Animator API;
- `Assets/TankWarfare/Scripts/Core/LocalStatsDatabase.cs` — локальная защищённая запись;
- `Assets/TankWarfare/Scripts/Network/WebSocketTransport.cs` — транспорт Editor/WebGL;
- `Server/src/server.js` — авторитетный сервер матча.

## Границы защиты

Секрет и данные находятся на устройстве владельца, поэтому никакая локальная WebGL-база не может быть полностью защищена от самого владельца устройства. Шифрование и HMAC защищают от чтения и простой подмены файла, а критичные результаты матча считаются сервером. Для соревновательной игры с глобальным рейтингом статистику нужно дополнительно хранить в серверной БД с учётными записями; для заданного локального учебного профиля текущая схема достаточна.
